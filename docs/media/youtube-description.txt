One world. One shared stash.

Guild Chest adds a gold-decorated chest that connects to one shared 32-slot inventory across your Valheim world. Build access points at your main base, mining camps, and distant outposts to reach the same supplies wherever you adventure.

FEATURES
• One shared inventory across every Guild Chest in the world.
• 32 slots, with metals accepted.
• Additional chests add access points, not capacity.
• One player can access the inventory at a time.
• Normal ward permissions apply.
• Contents remain saved if the last chest is destroyed. Rebuild a Guild Chest in the same world to access them again.

BUILD RECIPE
20 fine wood, 10 iron, 2 surtling cores, and 250 coins. A nearby workbench is required.

INSTALLATION
Install Guild Chest, BepInExPack Valheim, and Jötunn on every client and the host/server. Use matching Guild Chest versions.
