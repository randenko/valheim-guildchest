# Guild Chest 1.1.1

## Mod changes

- Fix shared-storage access and transfers on Valheim 1.0.20 by accepting its
  inventory format 110 while retaining support for saved format-109 contents.
- Verify AzuCraftyBoxes 1.8.28 compatibility, including the new Cookables filter
  group and individual item overrides. Native compatibility checks pass, and
  the user confirmed the compatibility build in game.
- Refresh the mod-manager package icon and cover screenshot.

## Publishing and documentation

- Add independent Nexus Mods and Hexium publishing alongside Thunderstore, with
  separate publishing switches and verification of the reviewed GitHub archive.
  Preserve Nexus file requirements and release changelogs when updating.
- Improve publication retries and recovery after interrupted requests. Verify
  existing uploads before retrying, and report unavailable Hexium scan results
  separately from verified archive and metadata publication.
- Group release notes and published changelogs under descriptive categories.
  Expand installation and publishing documentation with verified download
  links and recorded compatibility results.

## Development and validation

- Refresh game references at development-container startup, recover Steam
  reference downloads from stale manifests or incomplete installations, and
  consolidate build setup with Git and GitHub tooling.
- Add native regression checks for current and legacy inventory formats, item
  metadata preservation, unsupported-format rejection, and Cookables filters.
